# 长文档拆页：`new --from`

把一篇 Markdown / 纯文本报告拆成多页 spec，**全程本地规则、不调模型**。

```bash
slideforge new "供应链数字化改造" --from report.md -o out/doc.deck.yaml
```

支持的扩展名：`.md` / `.markdown` / `.txt` / `.text`。

| 参数 | 默认 | 说明 |
|---|---|---|
| `-o <path>` | 自动按标题命名 | spec 输出路径 |
| `--slides N` | 24 | 页数上限 |
| `--author <名字>` | 空 | 写封面署名 |
| `--theme <name>` | `midnight-executive` | 主题 |
| `--no-notes` | 开 | 关闭演讲者备注 |

## 拆页规则

- 文档的第一个 H1 是整篇标题，只用来取封面标题与副标题，**不进目录、不做章节**；其下的引言段落单独成「背景」页。
- 其余章节各成一章；文档完全没有 `#` 时也认「一、」「1. 」这类中文序号。一章展开 ≥ 2 页时自动插章节隔断页。
- 章节只取**最浅一级**标题：`##` 是章时，其下的 `###` 视为小节，正文与表格并回上一章，不单独进目录、不插隔断页。
- 每章第一页带 speaker notes，取自该章原文（去掉表格符号、超长截断）。
- 超页数上限时：先砍隔断页，再从尾部截断并保留结尾页。

## 图表数据抽取

- **Markdown 管道表格**：第一列当类目，任一列全是数值就能出图。类目多为年份 → `line`；百分比合计 ≈ 100% → `pie`；否则 `bar`。
- **正文数值序列**：如「华东 34%，华南 26%，华北 21%，西南 12%，其他 7%」，要求**同一句内 ≥ 3 个数值对**；跨行拼接时单位必须一致，否则宁可不出图。
- 图表右侧「解读」用该章前 3 条要点，剩下的要点另起文字页，避免同一句话在相邻两页重复。
- 每章最多抽一张图。

## 形态判断

| 原文出现 | 判定版式 |
|---|---|
| 「现状 / 目标」 | `compare` |
| 「首先 / 其次 / 然后 / 最后」 | `process` |
| ≥ 3 处日期 | `timeline` |
| 短句列表 | `cards` |
| 其余 | `bullets` |

## 用 Markdown 指令覆盖自动判断

写法借鉴 Marp / Slidev：

| 写法 | 作用 |
|---|---|
| `---` 独占一行 | 强制在此分页 |
| `<!-- layout: cards -->` | 指定该页版式，仅支持 `bullets` / `cards` / `process` / `timeline` / `compare` |
| `<!-- notes: 开场先讲结论 -->` | 指定演讲者备注，替代从原文截取 |

指令作用于它后面的那一页组。写错的版式名会被忽略，回落自动判断。

```markdown
## 一、现状

<!-- notes: 开场先讲结论 -->

营收同比增长 12%，但毛利率下降 3 个百分点。

---

<!-- layout: cards -->
<!-- notes: 这一页讲三个动作 -->

库存周转提升到 6 次。
履约周期压缩到 12 天。
缺货率控制在 4% 以内。
```

## 必须人工复核的地方

这是**规则抽取，不做语义纠错**：

- 口径混杂的句子会被主动放弃出图
- 图表只取一个数值列
- 拆出来的页数与版式分布需要通读一遍再 `build`
- 生成的 spec 是普通 YAML，直接改字段即可，不必回头改 Markdown
